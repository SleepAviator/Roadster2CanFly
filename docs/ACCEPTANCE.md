# Acceptance record

Checked locally on October 16, 2026, on an Apple M1 Max MacBook Pro with 64 GB RAM, Node 26, Three.js 0.186.1, and Rapier 0.21.0.

- All **149 physics, propulsion, and input tests pass**. The [complete parameter audit](PARAMETER_AUDIT.md) adds 99 checks of actual motion or landing forces (50 ramp settings, 49 kickflip settings), 20 expected unchanged cases, and two schema coverage checks. It covers all seven settings on each of the four nozzles. Existing tests cover successful defaults, airflow sensitivity, explicit Auto throttle compensation, finite tank depletion, mass conservation, pressure/flow/speed limits, force and moment balance, invalid inputs, and setup round trips.
- The GitHub Pages production build succeeds. The deployable site is approximately **5.01 MB** and includes the WebAssembly physics engine. No runtime dependencies were added for the new controls.
- The project, dependencies, and build occupy approximately **85 MB**, below the **1 GB** budget enforced by `npm run check:size`.
- Both default scenes reach **Landing complete** in the Codex in-app browser. The ramp reports **1.39 m/s** touchdown, **1.81× weight** peak wheel support, and **177.5 bar gauge** remaining tank pressure. The kickflip reports **1.42 m/s**, **1.83× weight**, and **210.8 bar gauge**.
- The browser now shows **Preset lift programme** as the default thrust mode. Changing only the kickflip's full-valve flow produces **2.5 m** peak rise and a semi collision at **90 kg/s**, a **7.5 m** successful default run at **120 kg/s**, and **21.2 m** peak rise with a hard landing at **150 kg/s**. These checks used the actual numeric input and Run button, rather than only checking the supply-capacity display.
- Peak rise remains visible in telemetry after a run. Selecting **Auto throttle · hold target path** resets the scene and explains that the controller can compensate for spare flow capacity.
- All four supply inputs were edited in the browser. Changing the speed limit to 400 m/s, rated flow to 80 kg/s, tank pressure to 25 bar gauge, and volume to 400 L updates the supply capacity to **8.3 kN** and usable air to **11.9 kg**.
- Front-left direction angles, valve percentage, enable switch, fixed/assisted steering, firing start, and duration were exercised. Switching to the front-right editor leaves its defaults intact; returning to the front-left editor retains its distinct settings.
- Every exposed numeric editor, assistance switch, thrust mode, and nozzle setting was changed through the browser UI in both scenes. The copied version-2 setup was decoded and all **50 ramp / 49 kickflip values** matched the edits. All **19 ramp / 18 kickflip sliders** were separately exercised with keyboard input; their committed setup values matched the displayed upper bounds. This checks UI-to-configuration wiring; the automated sensitivity runs check configuration-to-physics behavior.
- Reducing only kickflip damping from 4.5 to 1 kN·s/m per wheel caused a browser run to reach **8.1 m** peak rise and fail with a hard landing, matching the headless case (5.06 m/s touchdown). Control notes now explain reserve, unused request/valve ceilings, the travel threshold, drag-dependent wind, assisted firing demand, and fixed firing after touchdown.
- A version-2 setup link restores supply values and the front-left nozzle's angles, start/duration, valve percentage, steering, and enable state. JSON parsing and serialization are also covered by automated tests. Clipboard sharing was verified for the full browser control audit. The browser file-picker automation previously stalled; direct JSON file upload and revised download files remain unverified in this browser run.
- Impossible tank-air/loaded-mass combinations display a clear error and keep the last valid value. Restoring the successful preset resets the controls and badge.
- Playback and scene switching were exercised. The desktop layout was visually inspected with no horizontal overflow. The browser console reported no errors during the successful runs.

The preview image is from the running app. Temporary fixtures and formatter caches were removed after checks. The user-requested local review server remains available. This record verifies computational and browser behavior; it does not validate Tesla hardware, real-gas flow, pressure-vessel structure, or physical landing safety.
